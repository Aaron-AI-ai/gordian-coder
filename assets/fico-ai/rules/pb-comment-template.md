# Online 주석 템플릿

> Controller, Service, Mapper에 적용하는 주석 표준 템플릿입니다.
> Rule에서 pointcut처럼 참조하여 일관된 문서화를 유지합니다.

---

## 1. Controller

### 클래스 주석

```java
/**
 * 제목 : {서비스 한글명} Controller
 *
 * @author FICO AI
 * @since {yyyy.MM.dd}
 *
 * <pre>{@code
 * 서비스아이디 : {서비스ID}Controller
 * 서비스한글명 : {서비스 한글명} 컨트롤러
 * 설 명 : {서비스 설명 1~2문장}
 *
 * [API 엔드포인트]
 * - POST /{Collection ID}/{서비스ID} : {서비스 한글명}
 *
 * =================================================================================================
 * <<< 프로그램 변경 정보 >>>
 * -------------------------------------------------------------------------------------------------
 * 변경 일자 : 변경자 : 변경 내역
 * -------------------------------------------------------------------------------------------------
 * {yyyy.MM.dd} : {작성자} : {변경 내용}
 * =================================================================================================
 * }</pre>
 */
```

### 메서드 주석

```java
/**
 * {서비스 한글명} API
 *
 * <pre>
 * 서비스아이디 : {서비스ID}
 * 서비스한글명 : {서비스 한글명}
 * 설 명 : {서비스 설명 1~2문장}
 *
 * [요청 파라미터]
 * - {필드명} : {필드 설명} ({필수/선택})
 *
 * [호출 예시]
 * POST /{Collection ID}/{서비스ID}
 * {
 *   "data": { "{필드명}": "{예시값}" }
 * }
 * </pre>
 *
 * @param param 요청 파라미터 ({서비스ID}In 래핑)
 * @return 처리 결과
 */
```
