# fico-ai 사용 가이드

## fico-ai란

**fico-ai**는 AI 에이전트(OpenCode 등)에 **플러그인으로 붙어서, 우리 도메인(fico 프레임워크·사내 규칙)에 최적화된 코딩 에이전트를 만들어 주는 하네스**입니다.
범용 에이전트가 모르는 프레임워크 규칙·KB·프로젝트 규칙을 에이전트에게 주입하고, 리뷰·로그 분석 같은 작업을
정해진 단계(계획 → 병렬 수행 → 검증 → 리포트)로 강제해서 결과의 품질을 일정하게 유지하는 것이 목표입니다.

현재 제공하는 작업: **`/f-review`**(코드 리뷰), **`/f-log`**(에러 로그 분석). 설치 파일 이름은 `gdc`(gordian-coder)입니다.
