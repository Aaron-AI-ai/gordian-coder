# 0.2.5 릴리스 노트

## Windows · git 미사용 프로젝트에서 병렬 리뷰가 0/N 등록되던 문제 수정

git 저장소가 아닌 프로젝트(예: `D:\pb\ac-acnt`)에서 `--files`에 디렉터리나 글롭을 주면
파일 목록을 디렉터리 순회로 만드는데, Windows에서는 그 경로가 백슬래시(`ac-acnt-online\src\main\…`)로
run에 저장됐습니다. 서브에이전트의 run 합류 검사는 슬래시 경로로 비교하므로 45개 유닛 전부
"not a target"으로 거부되고, 각자 단독 세션으로 폴백해 `fcq/report/f-review/`에 파일별 리포트만
수십 개 남고 취합 리포트는 비어 있었습니다.

파일 목록을 git 목록과 같은 슬래시 형식으로 통일했습니다 (`src/core/review/tools/read.ts`).
macOS/Linux와 git 저장소에서는 동작 변화가 없습니다.

설치는 `docs/guides/gdc-install-windows.md`를 따릅니다. 이전 실행이 남긴 `fcq/f-review/runs/2026-10-23_*`와
`fcq/report/f-review/review-2026-10-23_*.md`는 지워도 됩니다.
